# Безопасность

Не публикуйте уязвимости, ключи, вебхуки, клиентские документы, выгрузки CRM и рабочие логи в публичных Issues/PR. Для конфиденциального сообщения используйте Security → Report a vulnerability, если эта функция доступна, либо закрытый канал, согласованный с владельцем AlexNovikov77. Не раскрывайте детали, пока канал не согласован.

Поддерживается актуальный main; отдельные production-установки должны иметь зафиксированный SHA и владельца обновлений. Dependabot открывает PR с обновлениями, но не подтверждает отсутствие уязвимостей и не выполняет автоматический деплой.

PR и evals работают без production-секретов. Для интеграций применяются минимальные права и режим чтения до отдельной приёмки. Изменения аутентификации, доступа к данным и операций записи требуют проверки владельцем. В CI нельзя исполнять код PR с ключами через pull_request_target.
