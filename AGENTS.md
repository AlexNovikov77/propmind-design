# Работа с репозиторием

- Это публичный репозиторий UI-концептов и пилотов PropMind. Основной Python-код и интеграции находятся в приватном AlexNovikov77/propmind. Не переносите сюда его рабочие данные и конфиги.
- Прочитайте README.md и docs/BACKLOG.md перед изменением назначения или архитектуры.
- Правила приёмки и релизов — в docs/DEVELOPMENT.md. Зависимости разработчика устанавливаются через npm ci; обновления приходят отдельными PR Dependabot.
- Статический сайт работает под префиксом /propmind-design/. Используйте относительные ссылки; проверяйте четыре публичные страницы.
- Логика данных находится в assets/registry.mjs; браузерный интерфейс — в assets/evidence.mjs. У приложения нет сетевых зависимостей.
- Перед завершением выполните npm test, npm run check и git diff --check. Изменения поведения UI проверяйте в браузере на компьютере и телефоне.
- Не теряйте sourceFile, revision, excerpt, location, review и history. Любое содержательное изменение проверенной записи требует повторной проверки человеком.
- Не выдавайте концепты, учебные записи, неподключённые API и ручные действия за работающую автоматизацию.
- Не сохраняйте в публичном репозитории клиентские документы, заполненные реестры, персональные данные и секреты.
- Содержательные изменения оформляйте в отдельной ветке и PR с проверками. Не переписывайте main и не обходите ограничения доступа.
- Различайте локально подготовленное, сохранённое в GitHub, прошедшее CI и опубликованное на Pages. Если доступ заблокирован, завершите доступную подготовку и укажите конкретный недостающий доступ.
