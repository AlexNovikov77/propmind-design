# Как цитировать PropMind

Автор и владелец продукта: Алексей Новиков / Aleksei Novikov, GitHub [AlexNovikov77](https://github.com/AlexNovikov77).

## Выбрать правильный материал

Этот публичный репозиторий содержит UI-пилот и ручной Evidence Register. Ссылка на него не подтверждает доступ к приватному ядру, автоматический IFC/PDF-анализ, внедрение у клиента или качество модели. Для обсуждения продуктового направления используйте [обзор продукта](PRODUCT.md), для поведения интерфейса — точную версию исходников и [архитектуру](ARCHITECTURE.md).

Файл [CITATION.cff](../CITATION.cff) задаёт машинно-читаемые авторство и название именно публичного UI-пилота. DOI, ORCID и дата релиза не указаны: подтверждённые идентификаторы и опубликованный выпуск пока не оформлены. Версия npm-пакета сама по себе не заменяет GitHub Release или архивную публикацию.

## Указать точный commit

В статье, исследовании или презентации укажите автора, название, репозиторий, полный SHA использованной версии и дату обращения. Не используйте движущуюся ветку main как единственное указание версии.

Пример для уже существующей базы UI:

> Novikov, A. PropMind: public UI pilot and Evidence Register. Commit f12d8469ad6323927ceec473d46f78389c8390e3. https://github.com/AlexNovikov77/propmind-design/tree/f12d8469ad6323927ceec473d46f78389c8390e3. Дата обращения: 20.10.2026.

Если использована другая ревизия, замените SHA, ссылку и дату. Для ссылки на эту документацию откройте файл на GitHub, выберите постоянную ссылку на его commit и сохраните её вместе с цитатой.

## Что даст файл цитирования

После попадания CITATION.cff в ветку по умолчанию GitHub предусматривает пункт «Cite this repository» и представления APA/BibTeX. Наличие файла в подготовленном PR ещё не означает появления пункта на main. Этот файл облегчает правильную ссылку; он не создаёт внешних цитирований и не измеряет их количество.

Цитирование не предоставляет лицензию на код, методику или клиентские данные. Публичная видимость и правила атрибуции не являются разрешением коммерческого использования или распространения. Права согласуются отдельно; новая лицензия этим изменением не выдаётся.

DOI можно оформить для отдельно принятой публичной архивной версии после решения владельца. Автоматическая публикация, создание релиза и подключение архивного сервиса здесь не выполняются.

Официальные правила: [GitHub — CITATION files](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), [Citation File Format](https://citation-file-format.github.io/).
