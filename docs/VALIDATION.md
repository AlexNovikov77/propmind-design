# Проверка v0.1 · 15 октября 2026

## Локальные результаты

- npm test: 18 тестов пройдены. Проверены доказательства, статусы и повторная приёмка, PDF/IFC-координаты, JSON, лимиты, бэкап и отказ записи.
- npm run check: четыре публичные HTML-страницы, локальные ссылки, якоря и синтаксис JavaScript.
- git diff --check: ошибок пробелов нет.
- HTTP-сервер: семь публичных маршрутов и типы модулей проверены; перенаправление сохраняет префикс проекта, служебные пути недоступны.

## CI и браузер

Workflow [Validate site](https://github.com/AlexNovikov77/propmind-design/actions/workflows/validate.yml) проверяет каждый PR и main. Отдельное задание browser устанавливает Playwright 1.64.1 и Chromium, запускает scripts/browser-smoke.mjs и сохраняет снимки на 7 дней.

Сценарий проверяет страницы на ширине 1440, 390 и 320 px; создание и редактирование, приёмку, сохранение после перезагрузки, JSON-перенос и восстановление, HTML как обычный текст, конфликт вкладок, отказ/повреждение хранилища и клавиатурные вкладки концепта Битрикс24.

Локально Chromium установить не удалось; локальный браузерный результат не заявляется. Источник результата удалённой проверки — завершённое задание browser на текущем SHA в PR. Проверка unit не заменяет его.
